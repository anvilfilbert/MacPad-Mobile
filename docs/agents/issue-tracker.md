# Issue tracker: GitHub

Issues and PRDs live as GitHub issues. Use `gh` from this repository.

- Create, read, comment, label, and close issues with `gh issue`.
- Publishing to the tracker means creating a GitHub issue.
- Fetching a ticket means reading its full body, labels, and comments.
- Pull requests are not a request or triage surface.
- Use native GitHub blocking dependencies where available.
- Otherwise record `Blocked by: #<issue>` in the issue body.
