# MacPad Mobile public product identity

MacPad Mobile is the customer-facing product name. Compatibility-sensitive Xcode targets, Swift modules, bundle identifiers, storage paths, tests, and implementation types retain the internal `PhonePad` identifier until a separately designed migration requires changing them.

The `anvilfilbert/PhonePad` repository is currently public, superseding ADR-0011's statement that it is private and publication is undecided. Public source availability is not an installable customer release and does not imply an App Store, TestFlight, download, support, or redistribution commitment. No current repository license has been approved; license selection, historical-license treatment, and bundled-asset rights remain explicit owner or legal decisions.
