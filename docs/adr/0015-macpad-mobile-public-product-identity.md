# MacPad Mobile public product identity

MacPad Mobile is the customer-facing product name. Compatibility-sensitive Xcode targets, Swift modules, bundle identifiers, storage paths, tests, and implementation types retain the internal `PhonePad` identifier until a separately designed migration requires changing them.

The `anvilfilbert/MacPad-Mobile` repository is public, superseding ADR-0011's statement that `anvilfilbert/PhonePad` is private and publication is undecided. Public source availability is not an installable customer release and does not imply an App Store, TestFlight, download, support, or redistribution commitment. The product owner approved the repository's no-license rights statement: no permission to use, copy, modify, or distribute the source or bundled artwork is granted. Historical-license treatment remains a separate legal decision and Git history is not rewritten by this decision.
