# TestFlight-upload-ready from the first release

PhonePad's first release is version `1.0.0`, build `1`, and targets a signed archive with stable bundle identity, app icons, privacy metadata, distribution configuration, and Xcode preflight suitable for a later TestFlight upload. Its permanent bundle identifier is `com.anvilfilbert.PhonePad`, and its version sequence is independent of MacPad. Bundle ID registration, signing-profile creation, and Apple-connected Validate App are prerequisites for the final upload-ready gate and each requires explicit approval before it occurs; local implementation and tests do not imply that approval. When upload is separately approved, distribution must use `TestFlight & App Store` rather than Internal Only so the Build retains future external-testing and release options. App Store Connect record creation, upload, processing, or distribution remains separately approval-gated.
