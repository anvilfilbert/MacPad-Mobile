# Native Apple design with a MacPad Mobile logo

MacPad Mobile preserves MacPad Capability Parity through current Apple Human Interface Guidelines rather than reproducing desktop chrome: it uses system navigation, sheets, menus, External Open routing, print controls, adaptive layouts, Dark Mode, Dynamic Type, accessibility, touch, pointer, and hardware-keyboard conventions for iPhone and iPad. Its app icon uses MacPad's established `Resources/MacPadLogo.png` mark (visual reference SHA-256 `b572225699c060beb2589b9dad3590b221cd3e45736aa6e51b03f0fa531a6a75`) and adds a compact `MOBILE` badge in the existing cyan-blue accent. This preserves the recognizable document, pen-shaped `M`, depth, and dark visual language while distinguishing the mobile product. The artwork is packaged as Apple-compliant 1024-by-1024 iOS and iPadOS icon assets with default, dark, and tinted appearances.
