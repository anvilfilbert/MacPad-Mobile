# Native Apple design with a sibling PhonePad logo

PhonePad preserves MacPad Capability Parity through current Apple Human Interface Guidelines rather than reproducing desktop chrome: it uses system navigation, sheets, menus, External Open routing, print controls, adaptive layouts, Dark Mode, Dynamic Type, accessibility, touch, pointer, and hardware-keyboard conventions for iPhone and iPad. Its app icon is a sibling design in the established style of MacPad's `Resources/MacPadLogo.png` (visual reference SHA-256 `b572225699c060beb2589b9dad3590b221cd3e45736aa6e51b03f0fa531a6a75`), replacing the identifying `M` with a `P` while retaining the recognizable document, blue accent, depth, and dark visual language. The new artwork must be packaged as Apple-compliant iOS and iPadOS icon assets and appearance variants.
