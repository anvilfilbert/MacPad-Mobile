# Independent PhonePad repository

PhonePad is independently implemented, tested, versioned, and released from the private `anvilfilbert/PhonePad` repository. MacPad behavior may be used as an observable product reference, but GPL-covered MacPad source and tests are not copied, ported, linked, or packaged; PhonePad has no source, package, build, or release dependency on MacPad and this work does not modify the MacPad repository. Whether PhonePad source becomes public, and under which license, is deliberately undecided and requires a separate future decision before publication.
