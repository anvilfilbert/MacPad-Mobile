# Edit files in place

Apple Files is the source of truth for saved PhonePad Documents. PhonePad opens and edits original Files in place, including Files provided by iCloud Drive or third-party providers, and new Documents are saved to a location the user chooses; PhonePad does not maintain a private document library. It registers as an editor only for `public.plain-text`, with opening in place enabled, so an External Open from another app or the system Share Sheet can route a compatible File into PhonePad without a generic Share Extension or inbox. Manual Open additionally permits generic data to reach strict content validation so extensionless plain text remains usable. Durable writable input uses normal in-place rules; read-only or ephemeral input becomes an unsaved Document requiring Save As. A File may have only one bound Tab, and active Tabs plus pending recovery identities are checked before Open, Save As, recovery attachment, or Locate Original. Internal recovery copies exist only to prevent loss and never become canonical Files.
