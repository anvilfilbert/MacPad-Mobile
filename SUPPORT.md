# Support

## Before opening an issue

MacPad Mobile requires iOS 18 or iPadOS 18 or later. This repository does not
currently provide a verified App Store, TestFlight, or downloadable release.

Check these safety points first:

- Save is explicit. Unsaved edits do not overwrite the original File.
- A read-only or detached Document must be saved with Save As.
- A File Conflict must be resolved before Save can continue.
- Preserved unsaved work appears in Document Recovery and never opens
  automatically.

## Public support routes

- [Report a reproducible bug](/anvilfilbert/PhonePad/issues/new?template=bug-report.yml)
- [Request customer support](/anvilfilbert/PhonePad/issues/new?template=support-request.yml)

Include the iPhone or iPad model, iOS or iPadOS version, and a short sequence of
steps. If the problem involves a File provider, name the provider and say
whether the File was opened from Files or another app.

Do not include Document content, account details, credentials, private file
paths, personal information, or unredacted screenshots. GitHub issues are
public when this repository is public.

Security vulnerabilities need a private route. Follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.
